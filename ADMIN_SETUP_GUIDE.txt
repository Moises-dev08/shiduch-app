## PART 2: How Admin System Works
===============================================

### Admin Login Flow:
1. Admin logs in with: bichadforever@gmail.com / bichadforever123456
2. System checks if user is in admin_users table
3. If admin → Routes to /admin/dashboard
4. If regular user → Routes based on profile status

### Admin Dashboard Features:
- View all pending profiles (status = 'pending')
- See complete profile details:
  * Personal information
  * Photos
  * Location details
  * Contact information
  * Bio and additional info
- Approve profiles (status → 'approved')
- Reject profiles with reason (status → 'rejected')
- Refresh to see new submissions

### Database Structure:
- admin_users table: Stores admin user IDs
- profiles table: Has RLS policies allowing admins to view/update all profiles
- Edge Functions: Handle approval/rejection logic with admin verification

## PART 4: Troubleshooting
===============================================

If Admin Dashboard shows "Access Denied":
- Verify admin user exists in admin_users table
- Check that email matches exactly
- Logout and login again

If Edge Functions fail:
- Check they are deployed in Supabase Dashboard → Edge Functions
- Verify SUPABASE_URL and SUPABASE_ANON_KEY env vars are set
- Check function logs in Supabase Dashboard

If images don't load:
- Verify storage bucket 'profile-pictures' exists
- Check storage policies are set correctly
- Ensure user has uploaded images during profile creation
