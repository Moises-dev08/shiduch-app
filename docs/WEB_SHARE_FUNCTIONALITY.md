# Web Share Functionality

This document explains the platform-specific share functionality implemented in the app.

## Overview

The app now supports different sharing behaviors based on the platform:
- **Mobile (iOS/Android)**: Uses native Share API to share via installed apps
- **Web**: Shows a custom modal with shareable URL and social media options

## Implementation

### 1. Updated Hook: `useProfileShare`

**Location**: `hooks/useProfileShare.ts`

**New Features**:
- Platform detection for web vs mobile
- Web share modal state management
- Copy to clipboard functionality
- Social media sharing options

**Returns**:
```typescript
{
  isSharing: boolean;                    // Loading state
  shareProfile: (profile) => Promise;    // Main share function
  showWebShareModal: boolean;            // Web modal visibility
  webShareUrl: string;                   // URL to share
  closeWebShareModal: () => void;        // Close modal
  copyWebShareUrl: () => Promise;        // Copy URL to clipboard
}
```

### 2. New Component: `WebShareModal`

**Location**: `components/WebShareModal.tsx`

**Features**:
- Clean, professional modal design
- URL display with copy button
- Social media share options:
  - WhatsApp
  - Facebook
  - Twitter
  - Email
- Desktop-optimized layout (max-width 500px)

**Props**:
```typescript
{
  visible: boolean;          // Modal visibility
  url: string;              // URL to share
  onClose: () => void;      // Close handler
  onCopy: () => Promise;    // Copy handler
}
```

### 3. Integration

Integrated into:
- **Profile Tab** (`app/(tabs)/profile.tsx`) - Share your own profile
- **Profile Details** (`app/profile-details.tsx`) - Share other profiles

## How It Works

### Mobile Flow:
1. User taps "Share" button
2. Native share sheet appears
3. User selects app to share (WhatsApp, Messages, etc.)
4. Message includes profile name and URL

### Web Flow:
1. User clicks "Share" button
2. Custom modal appears with shareable URL
3. User can:
   - **Copy link** - Copies URL to clipboard with confirmation
   - **Share via social media** - Opens share dialog in new tab:
     - WhatsApp Web
     - Facebook
     - Twitter
     - Email client

## URL Format

Profile URLs follow this format:
```
https://yourdomain.com/profile/{profileId}
```

The URL is generated by `getProfileHttpsShareUrl()` from `lib/profileShareUrls.ts`.

```typescript

  // Show web modal

  // Use native Share API
```

## Maintenance

### Adding New Social Platforms

To add a new platform:

1. Add button in `WebShareModal.tsx`:
```tsx
<TouchableOpacity style={styles.shareOption} onPress={shareOnNewPlatform}>
  <View style={[styles.iconCircle, { backgroundColor: "#COLOR" }]}>
    <Ionicons name="logo-newplatform" size={24} color="#fff" />
  </View>
  <Text style={styles.shareOptionText}>New Platform</Text>
</TouchableOpacity>
```

2. Add share function:
```tsx
const shareOnNewPlatform = () => {
  const url = `https://newplatform.com/share?url=${encodeURIComponent(url)}`;
  openInNewTab(url);
};
```

### Updating Share Message

Modify the message in `hooks/useProfileShare.ts`:
```typescript
message: `Your custom message here!\n\n${webUrl}`,
```

## Troubleshooting

### "Copy" button not working
- Check if `expo-clipboard` is installed: `npx expo install expo-clipboard`
- Ensure `import * as Clipboard from "expo-clipboard";` is present

### Social media links not opening
- Check browser popup blockers
- Verify URLs are properly encoded with `encodeURIComponent()`

### Modal not appearing on web
- Check `Platform.OS === "web"` detection
- Verify `showWebShareModal` state is being set
- Check console for errors
